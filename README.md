# Proyecto Final: Minería de Datos

Proyecto desarrollado bajo la metodología **CRISP-DM** para la predicción de contratación de depósitos bancarios (CDT) mediante modelos de aprendizaje automático y despliegue interactivo.

## Entregables del Proyecto
En la raíz de este repositorio se encuentran todos los entregables requeridos:

1. **`Informe_CRISP_DM.docx`**: Documentación completa de todas las fases de la metodología CRISP-DM.
2. **`01_Preparacion_Datos.ipynb`**: Jupyter Notebook de preparación de datos, limpieza, análisis exploratorio e inclusión del perfilado (`pandas-profiling`).
3. **`02_Modelado.ipynb`**: Jupyter Notebook de ingeniería de características, balanceo, validación cruzada, entrenamiento de los modelos supervisados y ensambles, evaluación de métricas, análisis estadístico (ANOVA y Tukey) e hiperparametrización.
4. **`03_Despliegue.ipynb`**: Jupyter Notebook con el desarrollo y ejecución del despliegue mediante interfaz gráfica (Streamlit).
